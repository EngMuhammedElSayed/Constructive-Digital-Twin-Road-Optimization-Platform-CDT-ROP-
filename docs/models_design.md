# Data Model Design

## Project

Represents the entire Digital Twin project.

Contains:

- Project Information
- Geometry
- Traffic
- Cost
- Optimization Settings

---

## Road Geometry

Contains:

- Radius
- Grade
- Lane Width
- Shoulder Width
- Median Width
- Superelevation

---

## Traffic Data

Contains:

- Demand
- Capacity
- Peak Hour Factor
- Heavy Vehicle Percentage

---

## Cost Parameters

Contains:

- Pavement Cost
- ROW Cost
- Earthwork Cost
- Unit Prices

---

## Optimization Settings

Contains:

- NSGA-II Parameters
- Population Size
- Number of Generations
- Objectives
- Constraints
