# Datasets

This directory contains all input and reference datasets used by the Constructive Digital Twin Road Optimization Platform.

## Structure

- sample_projects/
- terrain/
- alignments/
- traffic/
- costs/
- standards/
- optimization/
- outputs/
- templates/

## Purpose

The datasets are used for:

- Testing engineering calculations
- Optimization benchmarking
- Civil 3D integration
- Digital Twin synchronization
- Research validation
- Demonstration projects

No source code should be stored in this directory.
