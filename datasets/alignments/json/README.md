# Alignment JSON Files

## Purpose

This directory stores roadway alignment files in JSON format.

The application does not depend on any specific file in this directory.

Users can import or save JSON alignment files generated from:

- Autodesk Civil 3D
- LandXML conversion tools
- Excel conversion
- External applications
- CDT-ROP

## Notes

- No default alignment data is included.
- Users may add any number of JSON files.
- Imported files will be validated before being loaded into the Project model.
