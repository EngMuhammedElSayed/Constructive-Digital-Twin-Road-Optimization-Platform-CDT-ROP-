# Civil 3D Alignment Datasets

## Purpose

This directory stores sample Autodesk Civil 3D datasets used for testing,
validation, and demonstration of the Constructive Digital Twin Road
Optimization Platform (CDT-ROP).

## Supported Data

- Alignment
- Profile
- Corridor
- Surface
- Sample Line
- Feature Line
- Assembly
- Subassembly
- Pipe Network
- Section Views

## Supported File Formats

- DWG
- LandXML
- XML
- JSON
- CSV

## Future Integration

The Civil 3D Add-in will automatically read project data from this
directory during development and testing.

## Notes

No source code should be stored here.
