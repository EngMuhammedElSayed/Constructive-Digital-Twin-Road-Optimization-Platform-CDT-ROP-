# Alignment Datasets

This directory contains roadway alignment datasets used by the CDT-ROP platform.

## Purpose

These datasets provide the geometric input for:

- Horizontal Alignment
- Vertical Alignment
- Profile Generation
- Corridor Modeling
- Earthwork Calculation
- Optimization
- Civil 3D Integration

## Supported Formats

- Autodesk Civil 3D Export
- LandXML
- CSV
- JSON

## Directory Structure

alignments/
│
├── civil3d/
├── landxml/
├── csv/
└── json/

## Notes

All alignment files stored here are input datasets only.

No engineering calculations are performed inside this directory.
