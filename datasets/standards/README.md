# Engineering Standards

## Purpose

This directory stores engineering reference data used by the CDT-ROP platform.

Unlike project data, these files contain published engineering reference values defined by design standards.

## Supported Standards

- AASHTO
- Egyptian Road Design Code
- Highway Capacity Manual (HCM)

## Notes

- These files are reference datasets.
- They are independent of any specific project.
- Project input data should not be stored here.
- The Standards module loads these datasets when required by engineering calculations.
