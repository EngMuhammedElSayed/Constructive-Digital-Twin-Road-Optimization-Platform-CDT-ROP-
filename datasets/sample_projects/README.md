# Sample Projects

## Purpose

This directory stores complete sample projects used to demonstrate and test the CDT-ROP platform.

A sample project may contain all input files required to execute an engineering workflow.

Typical project contents include:

- Project configuration
- Alignment data
- Surface data
- Traffic data
- Cost data
- Design criteria
- Optimization settings

## Planned Project Structure

sample_project/
│
├── project.json
