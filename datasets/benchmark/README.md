# Benchmark Datasets

## Purpose

This directory stores benchmark datasets used to evaluate and compare the performance of engineering calculations and optimization algorithms.

Benchmark datasets are **not** required for normal project execution.

They are intended for:

- Performance testing
- Algorithm comparison
- Regression testing
- Research validation
- Optimization benchmarking

## Planned Usage

Future benchmark cases may include:

- Road alignment optimization
- Earthwork optimization
- Pavement cost analysis
- Traffic capacity analysis
- Multi-objective optimization (NSGA-II)

## Notes

- No benchmark datasets are included in the initial release.
- Benchmark files will be added during the Optimization Engine development phase.
