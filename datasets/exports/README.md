# Export Directory

## Purpose

This directory stores files generated by the CDT-ROP platform.

All exported files are created automatically by the application.

## Export Formats

- CSV
- Excel
- JSON
- LandXML
- PDF Reports

    ▼

## Notes

- Users should not manually edit exported files.
- Existing files may be overwritten during export.
- This directory is intended for generated output only.
