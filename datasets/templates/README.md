# Data Templates

## Purpose

This directory contains template files used to prepare project input data.

Templates define the required file structure and field names without containing project-specific values.

## Available Templates

- Alignment CSV
- Traffic CSV
- Cost CSV
- Project JSON
- Optimization JSON
- LandXML

## Notes

- Templates contain only the required structure.
- Users should copy a template and populate it with project data.
- Templates are compatible with the CDT-ROP import system.
