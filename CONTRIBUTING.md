# Contributing Guidelines

Thank you for your interest in contributing to this project.

Currently, this repository is under active research and development.

## Development Workflow

1. Update documentation if required.
2. Implement the feature.
3. Test the implementation.
4. Commit changes with meaningful commit messages.

## Coding Rules

- Follow Python PEP8.
- Use descriptive variable names.
- Add type hints whenever possible.
- Document all public classes and functions.
- Keep functions focused on a single responsibility.

## Branch Strategy

Main branch:

- main

Future development branches:

- feature/calculations
- feature/optimization
- feature/civil3d
- feature/gui

## Pull Requests

External contributions will be accepted after the first stable release.
