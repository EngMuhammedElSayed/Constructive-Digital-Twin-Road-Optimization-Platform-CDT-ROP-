# Fonts

## Purpose

This directory contains font resources used by the CDT-ROP application.

Fonts stored here are embedded with the application and are used by the graphical user interface (GUI), reports, dashboards, and exported documents.

---

## Planned Fonts

The following fonts are recommended:

- Inter
- Segoe UI
- Roboto
- Noto Sans
- Noto Sans Arabic

---

## Usage

Fonts in this directory may be loaded by:

- GUI
- Reporting Engine
- PDF Export
- Charts
- Dashboards

---

## Supported Languages

- English
- Arabic

---

## Notes

No fonts are currently distributed with the project.

Fonts will be added when the graphical user interface and reporting modules are implemented.
