## Project Overview

## Key Features

- Constructive Digital Twin
- Autodesk Civil 3D Integration
- BIM-Based Road Design
- Multi-Objective Optimization
- NSGA-II Solver
- AASHTO Compliance
- HCM-Based Capacity Analysis
- Cost Estimation
- Safety Assessment
- Pareto Front Visualization
- Engineering Report Generation
---
## Research Objectives

The project aims to:

- Develop an interactive Constructive Digital Twin framework.
- Optimize highway geometric design.
- Balance construction cost and roadway safety.
- Support engineering decision making.
- Integrate BIM with optimization algorithms.
- Enable future integration with Autodesk Civil 3D.
